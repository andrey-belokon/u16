# Проект μ16

μ16 — это простой 16-битный компьютер, включающий эмулятор, ассемблер, компиляторы и операционную систему.

| Каталог | Содержание |
| --- | --- |
| `b16c/` | компилятор языка B16 |
| `cpu16/` | эмулятор машины, ассемблер `cpu16asm`, стандартная библиотека, документация процессора, машины и ассемблера |
| `webdbg/` | веб-отладчик: эмулятор и ассемблер в браузере, диски и файловый менеджер ФС16 (`webdbg/cpu16_debugger.html`) |
| `monitor/` | монитор CPU16: ядро, оболочка, утилиты, загрузка с диска, спецификации (`monitor/docs/`), готовый загрузочный комплект (`monitor/dist/`) |

Сборка и проверка:

    cd cpu16 && make test           # эмулятор, ассемблер, библиотека; веб-отладчик через ../webdbg
    cd webdbg && make test          # веб-отладчик: сверка с C++, ФС16; make test-ui - интерфейс (Playwright)
    cd monitor && make test         # монитор

Запуск готовой системы: `cd monitor && ../cpu16/build/cpu16 --disk 0=dist/system.img dist/rom.bin`;
в веб-отладчике — подключить `monitor/dist/system.img` как диск 0 и загрузить `monitor/dist/rom.bin`.
