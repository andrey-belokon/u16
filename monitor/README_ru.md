# Монитор CPU16, ревизия 4

Однозадачная операционная система для машины CPU16: ядро с цепочкой процессов и файловой
системой ФС16, оболочка, утилиты, загрузка с диска. Спецификации — в `docs/`.

Каталог входит в проект из четырёх частей:

| Каталог проекта | Содержание |
| --- | --- |
| `../b16c/` | компилятор B16 |
| `../cpu16/` | эмулятор, ассемблер, документация машины |
| `../webdbg/` | веб-отладчик (в нём можно запустить готовый комплект и работать с файлами томов) |
| `monitor/` | этот каталог |

## Сборка и проверка

    make            инструменты (../cpu16, ../b16c), монитор out/monitor.bin, стенд out/kmon
    make test       все сценарии стенда, затем то же со сборкой с -fcopy-params
    make system     загрузочный том out/system.img (код загрузки, ядро, оболочка, утилиты)
    make dist       готовый комплект dist/: system.img и rom.bin
    make clean      удалить out/

## Запуск

Готовый комплект, без сборки (см. `dist/README_ru.md`):

    ../cpu16/build/cpu16 --disk 0=dist/system.img dist/rom.bin

Своя программа вместо оболочки (образ монитора на голой машине):

    tools/b16build.sh tests/progs/thello.b16
    echo '{"sectors":512,"entries":[{"path":"/sys","dir":true},
           {"path":"/sys/shell.cx","src":"out/thello.bin"}]}' > h.json
    python3 tools/fs16tool.py build out/h.img h.json
    ../cpu16/build/cpu16 --disk 0=out/h.img out/monitor.bin

## Каталоги

| Каталог | Содержание |
| --- | --- |
| `docs/` | спецификации монитора (ниже) и отчёты по этапам `docs/reports/` |
| `kernel/` | ядро: B16 (`kernel.b16` и модули), ассемблер (`resident.asm`, `boot.asm`, `klib.asm`, `monitor.asm`); `abi.b16` — двоичный интерфейс, общий с программами |
| `boot/` | ПЗУ `rom.asm`, код загрузки тома `fsboot.asm` |
| `user/lib/` | интерфейс для программ: `sys.b16` (подключает объявления `sysdefs.b16` и обёртки `sys.asm`), `ulib.b16` (общие функции оболочки и утилит) |
| `user/shell/` | оболочка `shell.b16` (находит и сценарии BScript `имя.bs`) |
| `user/bin/` | утилиты: ls, cat, cp, mv, rm, mkdir, rmdir, attr, touch, df, mount, umount, sync, date, mem, fsck, sysboot |
| `user/fm/` | файловый менеджер `fm` (две панели, копирование, перемещение, удаление, просмотр, запуск, F4 — редактор) |
| `user/edit/` | текстовый редактор `edit`: текст, журнал отмены и буфер обмена — в кадрах расширенной памяти, файлы до 1,5 МБ; выделение Shift со стрелками, «Сохранить как» |
| `tests/progs/` | тестовые программы ядра с ассемблерными помощниками и общим `tlib.b16` |
| `tests/fm/` | ручная проверка fm: `run.sh`, тома `mkvol.py`, снимки экрана `show.py` |
| `tests/edit/` | случайная проверка редактора против модели: `stress.py` |
| `tests/scripts/` | сценарии клавиатуры для стенда (`*.scn`) и стартовые сценарии оболочки (`*.txt`) |
| `tools/` | стенд `kmon.cpp` (ключ `--profile` — число команд по адресам), `run_tests.py`, утилита томов `fs16tool.py`, `mksys.py` (файл ядра), `mksysvol.py`, `mkdamaged.py` (порча тома для проверки fsck), `b16build.sh` |
| `dist/` | готовый комплект: `system.img`, `rom.bin`, `README_ru.md` |
