# Монитор CPU16, ревизия 2, шаг 4: история команд, установка кода загрузки, окончательные ревизии документов

## 1. История команд

Оболочка, если её стандартный ввод — консоль, переводит консоль в сырой режим с `NOBREAK` и сама собирает строку из событий клавиатуры: символы, Backspace, Ctrl+U, Enter, Ctrl+C (отмена строки), Ctrl+Z на пустой строке (конец ввода) и **стрелки ↑ ↓** — последние 16 строк истории, без пустых и без повтора предыдущей; ↓ после последней строки возвращает то, что было набрано до просмотра истории. Перенаправленный ввод оболочка читает построчно, как сценарий. Программы, запущенные из оболочки, получают консоль в обычном строчном режиме.

## 2. Установка кода загрузки с самой машины

- **Ядро:** `DISK_IO` пишет секторы 1–3 на любом томе, в том числе смонтированном на запись — ядро их не использует и не кеширует. Запрос, выходящий за сектор 3, подчиняется общему правилу (`BUSY` для тома на запись).
- **Утилита `sysboot N [файл]`:** записывает код загрузки (по умолчанию `0:/sys/fsboot.bin`) в секторы 1–3 диска N; проверяет заголовок `CXBT` версии 1 и размер до 1536 байт, наличие тома ФС16 на диске и предупреждает, если на томе нет `/sys/monitor.sys`.
- **Системный том** содержит `/sys/fsboot.bin` — копию кода загрузки.

## 3. Проверка

`make test` проходит целиком (18 сценариев), в том числе с `-fcopy-params`. Новое:
- **shell** — история: ↑ с дописыванием к вызванной строке, ↑ ↑ к более ранней, ↑ ↓ с возвратом набранной строки;
- **fs** — запись секторов 1–3 смонтированного тома разрешена, запись через границу сектора 3 — `BUSY`;
- **sysboot** — на работающей системе: каталоги и файлы системы копируются на диск 1, `sysboot 1`, ошибки `sysboot` (не код загрузки, нет тома, отсутствие `monitor.sys`), установка на смонтированный том 0; затем стенд **загружает систему с диска 1** через ПЗУ, и скопированная оболочка выполняет свой `/sys/startup`.

Готовый комплект `dist/` пересобран и проверен в эмуляторе.
