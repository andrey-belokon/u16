## 2. Память

По «Системным вызовам», ревизия 2, разд. 7.6, 9.6:

| Вызов | Что делает |
| --- | --- |
| `SETTOP` (`$41`) | изменить собственную память процесса целыми страницами; новые кадры обнулены, `top` в PIB обновляется |
| `XALLOC` (`$42`) | обнулённый кадр расширенной памяти; номер кадра — его номер в машине |
| `XFREE` (`$43`) | вернуть кадр; страницы, где он стоял, получают собственный кадр или ничего |
| `XMAP` (`$44`) | поставить кадр в страницу 0–6, в том числе выше `top`; `XM_OWN` — вернуть собственный |
| `MEMINFO` | R3 — число кадров расширенной памяти процесса |

**Ядро:**
- таблица владельцев `owner[256]` вместо битовой карты `fmap`: 0 — свободен, `$FF` — ядро, 1–16 — процесс, `$FE` — новая программа на время `EXEC`;
- текущая карта процесса `Proc.map[7]`; память процесса — страницы с его кадрами, и буферы вызовов, адреса обработчиков, стек для доставки Ctrl+C проверяются по ней;
- при `EXIT` и `EXEC` освобождаются все кадры процесса по таблице владельцев.

Битовая карта страниц в описателе процесса не заведена: она повторяла бы таблицу владельцев.

**Монитор теперь называет себя ревизией 2** (`CPU16 monitor, revision 2`, `SYSINFO.version` = `$0200`). Утилита `mem` показывает расширенную память процесса.

**Размеры:** код ядра 23,5 КБ из 32, данные 7,4 КБ из 8 (свободно 570 байт), резидентная часть 878 байт.

## 3. Проверка

Новый сценарий **xmem** (оболочка `txmem`, `max_top` = `$A000`): `XALLOC`, кадр в странице выше `top`, два кадра по очереди в одной странице с сохранением данных, кадр в странице 6, буфер вызова через две страницы расширенной памяти, `READ` из файла в кадр расширенной памяти, `XM_OWN`, `FAULT` для страницы без кадра, `XFREE` отображённого кадра, ошибки `XFREE` и `XMAP`, `SETTOP` с ростом и уменьшением и обновлением PIB, ошибки `SETTOP`, исчерпание всей памяти (`NOMEM` у `XALLOC` и `SPAWN`) и возврат, освобождение кадров расширенной памяти потомка при `EXIT` и `EXEC`.

`make test` проходит целиком (17 сценариев), в том числе с `-fcopy-params`. Готовый комплект `dist/` пересобран.
