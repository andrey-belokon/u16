# Примеры программ CPU16

Все примеры подключают стандартную библиотеку строкой `.include "../lib/stdlib.asm"` (путь считается от файла примера).

- **Командная строка** (из корня проекта): `make examples` собирает все примеры в `build/examples/`. Один пример: `build/cpu16asm examples/snake.asm -o snake.bin`, запуск — `build/cpu16 snake.bin`.
- **Веб-отладчик:** вставьте текст на вкладку «Source» и соберите по Ctrl+B. Библиотека там встроена, строка `.include` работает как есть. Примерам с дисплеем нужна кнопка «Display» рядом с консолью: щёлкните по дисплею, чтобы клавиши уходили программе.

## Консоль

| Файл | Что делает | Что показывает |
|---|---|---|
| `calc.asm` | калькулятор: строки `a op b`, результат в десятичном и шестнадцатеричном виде | ввод строки, разбор из буфера, 32-битная арифметика, деление на 0 |
| `calc_exec.asm` | тот же калькулятор в формате исполняемого файла CX16; собирается с `--exec` (`make examples` делает это сам для `*_exec.asm`) | заголовок, буфер в `.reserve` за `image_end`, работа под монитором и на голой машине |
| `disk_demo.asm` | сведения о дисках из блока INFO и счётчик запусков в секторе 0; запуск: `cpu16 --disk 0=demo.img disk_demo.bin` | контроллер дисков: DRIVES, INFO, READ, WRITE, FLUSH, драйвер с опросом, коды ошибок |
| `hexdump.asm` | дамп собственного ПЗУ и таблицы векторов | указатели, байтовый доступ, шестнадцатеричный вывод |
| `primes.asm` | простые числа решетом Эратосфена, сумма, наибольший промежуток | массив в ОЗУ, `memset`, 32-битная сумма |

## Дисплей, клавиатура, таймер, часы

| Файл | Что делает | Что показывает |
|---|---|---|
| `display_demo.asm` | обзор: палитра, оформление, кириллица, значки, псевдографика, перекраска | координатный вывод, атрибуты, рамки |
| `keys.asm` | символ, его код, сканкод и название каждой нажатой клавиши; Esc — выход | чтение слова из `$FF20`, таблица сканкодов |
| `stopwatch.asm` | секундомер с крупными цифрами из блоков; пробел — старт/стоп, R — сброс | таймер 50 Гц, обработчик IRQ0, `WFI`, клавиши без ожидания |
| `clock.asm` | часы: дата, день недели и время крупными цифрами; H — час +1, M — минута +1, 0 — обнулить секунды, D — следующий день; при выходе печатает показания часов. Запуск с заданным временем: `cpu16 --rtc 31.12.2026T23:59:50 clock.bin` | часы реального времени: READ, WRITE_TIME, WRITE_DATE, проверка ERR, смена секунды опросом по тикам таймера |
| `snake.asm` | игра «змейка»; стрелки, пробел — пауза, Esc — выход | ходы по тикам таймера, карта поля в ОЗУ, кольцевой буфер, генератор случайных чисел |
| `tetris.asm` | «тетрис»: ← → сдвиг, ↑ поворот, ↓ быстрее, пробел — сбросить, P — пауза; демо — D на заставке или само через 30 с, любая клавиша возвращает на заставку | фигуры как битовые маски 4×4, поле в ОЗУ, удаление строк, «мешок» фигур, тень, 32-битный счёт, игрок-программа (перебор ходов и оценка поля) |

В эмуляторе командной строки примеры с дисплеем тоже работают: стрелки и функциональные клавиши терминала превращаются в сканкоды. Сам экран там не виден; ключ `--screen` печатает его содержимое по завершении.
