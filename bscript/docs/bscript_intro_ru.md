# Знакомство с BScript

BScript — язык для небольших программ, которые на B16 писать долго: пройти по каталогу, разобрать текст, запустить утилиту и проверить её вывод. Это введение показывает язык на примерах; точные правила — в «BScript — спецификация языка» (`bscript_spec_ru.md`).

## Зачем BScript и первая программа

Если вы писали на Go, Python или JavaScript, большая часть BScript покажется знакомой. Типы динамические, память освобождает сборщик мусора, строки, массивы и словари встроены. От B16 язык взял лексику: те же комментарии, те же правила конца строки, символьные литералы `'A'` как числа.

Самая короткая программа — одна строка. Сохраните её в файл `hello.bs`:

```text
println("hello, world")
```

и запустите из оболочки:

```text
bs hello.bs
```

Загрузчик `bs` скомпилирует файл в `hello.bsc` рядом и выполнит. Второй запуск пропустит компиляцию, если исходник не менялся. Если положить сценарий в текущий каталог или в `A:/bin`, оболочка найдёт его по имени, как обычную утилиту: `hello`.

Программа получает аргументы командной строки в массиве `args`:

```text
if args.len() == 0 {
    println("hello, stranger")
} else {
    println($"hello, {|args[0]|}")
}
```

Запись `$"...{|выражение|}..."` — интерполяция: значение подставляется в строку как текст.

**Сценарий и программа с `main`.** Код выше — сценарий: операторы стоят прямо на верхнем уровне и выполняются сверху вниз. Для программ побольше удобнее функция `main`; её результат — код завершения:

```text
fn main(args: array): int {
    if args.len() == 0 {
        eprintln("usage: hello name")
        return 2
    }
    println($"hello, {|args[0]|}")
    return 0
}
```

В программе с `main` на верхнем уровне допустимы только объявления. Смешивать два стиля нельзя.

**Строки и точки с запятой.** Конец строки завершает оператор, точка с запятой не нужна. Поэтому длинное выражение переносят только после знака операции, запятой или открывающей скобки:

```text
var total = first +
            second          // так можно
var wrong = first
            + second        // ошибка: первая строка уже закончилась
```

## Переменные, числа и строки

Переменная объявляется словом `var`, константа — `const`. Тип указывать не нужно, но можно; тогда он проверяется при каждом присваивании:

```text
var count = 0
var name: string = "report.txt"
var nothing                 // null
const LIMIT = 100
```

Значений восемь видов: `null`, `bool`, `int`, строки, массивы, словари, открытые файлы и ошибки. Узнать вид значения можно функцией `type(x)`.

**Числа.** Целое число одно — `int`, 16 бит со знаком, от −32768 до 32767. Переполнение молча заворачивается по модулю 2^16, как в B16: `32767 + 1` даёт −32768. Деление `/` округляет к нулю. Есть шестнадцатеричная (`$FF`, `0xFF`) и двоичная (`0b1010`) запись, битовые операции и сдвиги, включая логический `>>>`. Дробных чисел нет.

**Строки.** Строки неизменяемы и могут содержать любые байты. Их пишут в двойных кавычках или в обратных апострофах — второй вариант удобен, когда внутри есть кавычки:

```text
var a = "line\n"
var b = `он сказал "да"`
var c = a + b               // конкатенация
var n = c.len()             // длина в байтах
```

Число к строке само не приводится: `"n = " + 5` — ошибка. Пишите `"n = " + str(5)` или, лучше, `$"n = {|5|}"`. Обратно строку в число переводит `s.to_int()`.

Частые методы строк: `slice`, `find`, `split`, `lines`, `trim`, `replace`, `starts_with`, `upper`, `lower`, `pad_left`. Проверка подстроки — операция `in`: `"err" in line`.

**Символы — это числа.** `s[i]` возвращает байт как `int`, а `'A'` — код символа. Поэтому сравнивайте с символьным литералом, а не со строкой:

```text
if s[0] == '#' { continue }     // верно
if s[0] == "#" { continue }     // всегда false: число не равно строке
```

**Равенство.** `==` между значениями разных видов не ошибка, а просто `false`. Это делает безопасными проверки вроде `x == null` или `cfg["port"] == 80`. Массивы и словари равны, только если это один и тот же объект.

**`null` и `??`.** Отсутствующий ключ словаря, пустой `var`, конец ввода — всё это `null`. Операция `a ?? b` даёт `b`, если `a` равно `null`:

```text
var port = cfg["port"] ?? "8080"
```

## Условия и циклы

Условие пишется без скобок, фигурные скобки у блока обязательны:

```text
if n == 0 {
    println("none")
} else if n < 10 {
    println("few")
} else {
    println("many")
}
```

Условие должно быть именно `bool`. `if n { }` при числе `n` — ошибка выполнения; пишите `if n != 0 { }`. Логические операции `&&`, `||`, `!` тоже требуют `bool`.

**Три цикла.** `while` — с условием, `loop` — бесконечный, `for ... in` — перебор:

```text
var i = 0
while i < 10 { i++ }

loop {
    var line = io.read_line()
    if line == null { break }   // конец ввода
    println(line.upper())
}

for name in ["a", "b", "c"] { println(name) }
for i, ch in "abc" { println($"{|i|}: {|ch|}") }   // байты строки как числа
```

Массив, который перебирает `for`, нельзя удлинять или укорачивать в теле цикла; менять элементы на месте можно. Словарь перебирают через `m.keys()` или `m.values()`.

**`switch`** сравнивает значение с метками по порядку, без проваливания в следующую ветку. Метками могут быть любые выражения, в одной ветке — несколько через запятую:

```text
switch cmd {
case "add", "+":
    total += n
case "clear":
    total = 0
default:
    eprintln($"unknown command {|cmd|}")
}
```

Важное отличие от C: `break` и `continue` внутри `switch` относятся к циклу вокруг него. `break` в ветке выходит из цикла, а не из `switch`.

`++` и `--` — отдельные операторы, а не выражения: `i++` можно, `a[i++]` нельзя. Присваивание тоже оператор: `if (x = f()) ...` не пишется.

## Функции и ошибки

Функция объявляется словом `fn`. Типы параметров необязательны, типы результатов обязательны — по ним компилятор знает, сколько значений функция возвращает:

```text
fn greet(name: string) {
    println($"hello, {|name|}")
}

fn divmod(a: int, b: int): int, int {
    return a / b, a % b
}

var q, r = divmod(17, 5)        // 3, 2
var _, rest = divmod(9, 4)      // _ отбрасывает значение
```

Функцию можно вызвать до её объявления. Функции не бывают значениями: их нельзя положить в переменную или передать аргументом. Вложенных функций тоже нет. Если у функции есть результат, компилятор проверит, что каждый путь кончается `return`.

**Ошибки — это значения.** Функции библиотеки, которые могут не сработать (нет файла, нет места, неверное число), возвращают ошибку типа `error`. Главное правило: **ошибку, которую вы не перехватили, функция возвращает дальше сама**. Поэтому простейший сценарий вообще не проверяет ошибок, и всё равно ведёт себя правильно:

```text
var text = fs.read_text(args[0])
println(text.lines().len())
```

Если сценарий называется `count.bs`, а файла нет, он напечатает `count: notes.txt: no such file or directory` (как утилиты оболочки) и завершится с кодом 1.

**Перехват — лишняя переменная слева.** Добавьте к результатам вызова ещё одну переменную, и она получит ошибку (или `null`, если всё хорошо):

```text
var text, err = fs.read_text(name)
if err == errors.NOENT {
    text = ""                       // нет файла — это нормально
} else if err != null {
    eprintln($"{|proc.name()|}: {|err|}")
    return 1
}
```

Ошибки сравниваются по коду: `err == errors.NOENT` верно для любой ошибки «нет файла». У ошибки есть методы `code()`, `text()`, `object()` (обычно путь) и `where()` (место в исходнике).

**Своя ошибка — `fail`.** Оператор `fail` завершает функцию ошибкой, как `return` — значением:

```text
fn parse_port(s: string): int {
    var n, err = s.to_int()
    if err != null || n <= 0 {
        fail "bad port", s           // текст и объект ошибки
    }
    return n
}
```

`fail err` передаёт перехваченную ошибку дальше как есть. Свои коды ошибок начинайте с 1000: `fail "locked", name, 1001`.

**Ошибки программиста** — другое дело. Индекс за границей, деление на ноль, сложение числа со строкой не перехватываются: программа останавливается с сообщением `bsvm: файл:строка: текст` и кодом 125. Это сделано нарочно: такие ошибки исправляют в коде, а не обрабатывают.

## Массивы и словари

**Массив** — изменяемая последовательность любых значений, индексы с нуля:

```text
var a = [3, 1, 2]
a.push(5)
a[0] = 4
a.sort()                         // [1, 2, 4, 5]
println(a.len())                 // 4
if 2 in a { println("есть") }
var tail = a.slice(1)            // новый массив [2, 4, 5]
```

Ещё есть `pop`, `insert`, `remove`, `index_of`, `reverse`, `clear`, `clone`. Отрицательных индексов «с конца» нет: последний элемент — `a[a.len() - 1]`. `sort` умеет только массив целиком из чисел или целиком из строк.

**Словарь** — ключи-строки и любые значения. Ключи перебираются в порядке вставки:

```text
var m = {"name": "x", "size": 10}
m["owner"] = "root"
println(m["none"])               // null: ключа нет, это не ошибка
if "size" in m { m.delete("size") }
for k in m.keys() { println($"{|k|} = {|m[k]|}") }
```

Часто нужен счётчик по ключу — `get` со значением по умолчанию:

```text
var freq = {}
for w in words {
    freq[w] = freq.get(w, 0) + 1
}
```

**Ссылки, а не копии.** Массив и словарь передаются по ссылке: функция, которая получила массив, меняет тот же массив. Копию делает `clone()` (неглубокую: вложенные массивы остаются общими).

**Словарь в условии.** Открывающая фигурная скобка после `if`, `while`, `for` и `switch` начинает блок, поэтому словарный литерал там берут в скобки: `if key in ({"a": 1, "b": 2}) { }`. В обычном коде скобки не нужны.

Объём данных ограничен: строка и массив — до 32 767 байт или элементов, словарь — до 16 384 ключей. Если программе не хватает обычной памяти, VM сама переходит на расширенную, до 1 МБ; программу для этого менять не нужно, она только работает медленнее.

## Ввод-вывод, файлы и программы

Библиотека разбита на пространства: `io`, `fs`, `path`, `proc`, `str`, `time`, `errors`. Обращение — через точку: `fs.read_text(p)`. Самые частые функции доступны и без префикса: `print`, `println`, `eprint`, `eprintln`, а также `str`, `type`, `min`, `max`, `abs`, `assert`, `error`.

**Стандартные потоки.** `println` пишет в поток 1, `eprintln` — в поток 2 (сообщения об ошибках). Вывод буферизуется и записывается сам: при переводе строки на консоли, перед чтением ввода, перед запуском программы и при выходе. `io.read_line()` читает строку из потока 0 и возвращает `null` в конце ввода; `io.read_all()` — весь остаток.

**Файл целиком** — самый простой путь для небольших файлов:

```text
var text = fs.read_text("notes.txt")
fs.write_text("upper.txt", text.upper())
fs.append_text("log.txt", "done\n")
```

**Построчно** — через открытый файл:

```text
var f = fs.open("big.log", "r")          // "r", "w" или "a"
var n = 0
loop {
    var line = f.read_line()
    if line == null { break }
    if "ERROR" in line { n++ }
}
f.close()
```

Закрывайте файлы явно: одновременно открытыми может быть только 8 файлов программы. Забытый файл закроет сборщик мусора, но ошибка записи при этом потеряется. Файлы только текстовые: позиционирования, размера и двоичного чтения пока нет.

**Каталоги и пути.** `fs.list(dir)` возвращает массив словарей с ключами `"name"`, `"dir"`, `"hidden"`, `"system"`, `"rdonly"`. Пространство `path` работает с текстом путей, не трогая диск:

```text
for e in fs.list(".") {
    if !e["dir"] && path.match("*.txt", e["name"]) {
        println(path.join(fs.cwd(), e["name"]))
    }
}
```

Имена файлов на ФС16 не различают регистр. Сравнивайте их через `path.equal(a, b)` или `a.equal_fold(b)`, а не через `==`.

**Запуск программ.** `proc.run` запускает программу так же, как оболочка, ждёт её и возвращает код завершения. `proc.capture` вдобавок возвращает её вывод строкой. Перенаправления передаются словарём:

```text
var code = proc.run("b16c", ["prog.b16", "-o", "prog.s"])
if code != 0 { fail $"b16c failed: {|code|}" }

var rc, out = proc.capture("ls", ["/bin"])
proc.run("sort", [], {"stdin": "in.txt", "stdout": "out.txt"})
```

Ненулевой код потомка — не ошибка, его проверяете вы. Ошибка — это когда программу не удалось запустить (`errors.NOENT`, `errors.NOEXEC`). Если пользователь нажал Ctrl+C в потомке, сценарий тоже завершается.

**Подключение файлов.** Общие функции выносят в отдельный файл и подключают в начале программы:

```text
include "lib/text.bs"
```

Путь считается от каталога подключающего файла; повторное подключение пропускается. Все имена попадают в общее пространство программы, так что выбирайте их без конфликтов.

## Пример целиком и типичные ловушки

Сценарий ниже считает строки с меткой во всех `*.log` каталога. Он собирает вместе почти всё из этого введения: аргументы, `fs.list`, перехват ошибки с продолжением работы, чтение по строкам, интерполяцию.

```text
// logscan.bs — число строк с меткой в файлах *.log каталога
//   logscan mark [dir]
if args.len() < 1 {
    eprintln("usage: logscan mark [dir]")
    return 2
}
var mark = args[0]
var dir = "."
if args.len() > 1 { dir = args[1] }

var total = 0
// Ошибка чтения каталога не перехвачена: сценарий завершится
// сообщением «logscan: каталог: текст» и кодом 1.
for e in fs.list(dir) {
    if e["dir"] || !path.match("*.log", e["name"]) { continue }
    var name = path.join(dir, e["name"])
    var f, err = fs.open(name, "r")
    if err != null {
        eprintln($"{|proc.name()|}: {|err|}")   // сообщить и идти дальше
        continue
    }
    var count = 0
    loop {
        var line = f.read_line()
        if line == null { break }
        if mark in line { count++ }
    }
    f.close()
    println($"{|e["name"].pad_right(20)|} {|count|}")
    total += count
}
println($"total {|total|}")
```

Ещё примеры с эталонным выводом лежат в `examples/` реализации: `wc.bs`, `grep.bs`, `tree.bs`, `backup.bs`, `wordfreq.bs`, `calc.bs`, `todo.bs`, `checkutils.bs`.

### Ловушки

| Что пишут | Что происходит | Как правильно |
| --- | --- | --- |
| `if count { }` | ошибка выполнения: условие не `bool` | `if count != 0 { }` |
| `s[i] == "a"` | всегда `false`: байт — число | `s[i] == 'a'` |
| `"n=" + n` | ошибка выполнения: строка плюс число | `$"n={|n|}"` или `"n=" + str(n)` |
| выражение, перенесённое перед `+` | первая строка уже завершила оператор | переносите после знака операции |
| `break` внутри `switch` в цикле | выход из цикла, а не из `switch` | ветки `switch` не проваливаются, `break` там не нужен |
| `a == b` для массивов | сравниваются ссылки, а не содержимое | сравнивайте поэлементно |
| `fs.read_text(p).lines()` с проверкой ошибки | ошибка вызова внутри выражения не перехватывается | `var t, err = fs.read_text(p)`, затем `t.lines()` |
| `name == "README.TXT"` для имён файлов | регистр различается | `path.equal(name, "README.TXT")` |
| `a.push(x)` внутри `for x in a` | ошибка `array changed during iteration` | соберите изменения в новый массив |
| `30000 + 30000` | молча даёт −5536 | следите за диапазоном `int`: −32768…32767 |
| большой файл через `fs.read_text` | `errors.TOOBIG` дальше 32 767 байт | читайте построчно через `fs.open` |

Если что-то ведёт себя неожиданно, смотрите спецификацию: в ней каждое правило описано точно и проверено тестами реализации.
