# Примеры BScript

Сценарии и программы, показывающие язык и библиотеку фазы 1 («BScript», версия 1.1). Каждый пример проверяется автоматически: `make examples` (или `python3 tools/run_tests.py --examples`) кладёт каталог на том как `/ex`, выполняет команду из первой строки `// run: ...` и сравнивает вывод с `expected/ИМЯ.out`.

| Пример | Что показывает |
| --- | --- |
| `hello.bs` | самый короткий сценарий: `args`, интерполяция |
| `logscan.bs` | пример В.1 спецификации: `fs.list`, `path.match`, чтение строк файла, ошибка, перехваченная лишней переменной |
| `wc.bs` | программа с `main` и `include`, несколько результатов функции, сообщения в стиле утилит, код завершения |
| `grep.bs` | ключи командной строки и `switch`, `in` для строк, `lower()`, коды 0/1/2 |
| `tree.bs` | рекурсия, `fs.list`, флаги записей каталога, сортировка |
| `backup.bs` | копирование дерева каталогов, перехват `errors.EXIST`, собственный код ошибки, `fail` |
| `wordfreq.bs` | словари, ключ сортировки, разбор числа `to_int` с перехватом |
| `calc.bs` | калькулятор: рекурсивный спуск, переменные, ошибки разбора как значения `error`, ввод из потока 0 |
| `todo.bs` | список дел в файле: `fs.open`, запись и чтение, `errors.NOENT` как «файла ещё нет» |
| `checkutils.bs` | проверка утилит оболочки: `proc.run`, `proc.capture`, перенаправления, функции-проверки |
| `lib/text.bs` | общие функции, подключаемые `include` |

Данные примеров — в `data/`. Запуск на машине: скопировать каталог и выполнить `bs файл.bs ...` или, если сценарий лежит в текущем каталоге или в `A:/bin`, просто по имени: `wc poem.txt`.
